# Simplified Chinese (zh-CN) Glossary

The terms and style `zh-CN.json` follows. Check a new translation against this
file, and add a term here the first time it needs a decision.

## Stay in English

Product names and the concepts people see in commands, logs and documentation
keep their English form, so the interface matches what a Human types and reads
elsewhere.

| Term                                 | Note                                                |
| ------------------------------------ | --------------------------------------------------- |
| Linger, TeamHub                      | Product names.                                      |
| Agent, Room, Runtime, Skill, Routine | Product concepts.                                   |
| Another Me, Wiki                     | Feature names.                                      |
| CLI, PowerShell, npm, Node.js        | Tools.                                              |
| Claude Code, Codex, Pi, Antigravity  | App names.                                          |
| API, URL, BYOK, PDF, Markdown        | Abbreviations and formats.                          |
| Base URL, tokens, Dense, MoE         | Model terms people meet in provider documentation.  |
| Local Computer                       | Only when it names the background program.          |
| Reconnect This Computer              | A desktop menu item, quoted until it is translated. |

## Style

- Put one space between Chinese and Latin letters or digits: `连接 Agent`,
  `3 条未读消息`.
- Use full-width punctuation in sentences (`，` `。` `：` `？`) and `…` for an
  ellipsis.
- Labels, buttons, menu entries and tooltips have no closing period. Full
  sentences do.
- Address the Human as `你`, not `您`.
- Prefer the short everyday word a native app would use over a literal
  rendering of the English.
- Name a place in the interface by its label on screen, in Chinese quotation
  marks or as a path: `“消息”`, `设置 › 模型`.
- Keep every `{placeholder}` and `<tag>` of the English source; move them to
  where the Chinese sentence needs them.
